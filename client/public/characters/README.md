# Character Face Images Directory

Place custom AI Employee face images in this folder (`/public/characters/`).

### Recommended File Names & Formats:
- `farhan.png`
- `priya.png`
- `rahul.png`
- `ananya.png`
- `vikram.png`
- `sneha.png`

### Image Format & Resolution:
- Format: PNG / JPG / WebP
- Resolution: 300x300px or 500x500px square crop
- Aspect Ratio: 1:1 (Square)

If an image is missing or fails to load, the system will automatically display an elegant initial-letter fallback avatar.
